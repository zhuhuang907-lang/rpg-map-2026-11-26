# 女性向恋爱线·内容包与试玩页

- `suitang.json`：唐段内容包（10 类男主、20 场相遇、20 张火花、10 种爱情类型、四卷成书体例）。
- `play.html`：独立试玩页。不接 AI，用内容包跑「相遇—火花—日常—结局」，带四值、开局定制（世界模式/女主/男主类型/性情/故事类型）、一键成书下载。

## 怎么开

在本目录起一个本地服务器（不能双击打开，浏览器会拦 fetch）：

```bash
cd web/romance
python -m http.server 8765
```

浏览器打开 `http://127.0.0.1:8765/play.html`。

## 试玩页说明

- 这是给项目主人看「能不能玩」的竖切片，不是游戏本体。本体里的女性向开关默认关闭，要在开局打开；本体接入由宰相改 `web/game.src.html`。
- 内容包 schema 见 `中书省/附件/女性向恋爱线设计.md` 第十节；试玩记录见 `中书省/附件/女性向纸面试玩.md`。
- 改内容包后刷新页面即生效；试玩页只读 `suitang.json`。
